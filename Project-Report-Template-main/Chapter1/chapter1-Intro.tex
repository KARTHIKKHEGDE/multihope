\chapter{Introduction}

The project titled \textbf{Secure Multi-Hop Communication System using Socket Programming with Quantum-Inspired Key Exchange} focuses on the design and implementation of a peer-to-peer (P2P) encrypted messaging system that operates over a Local Area Network (LAN) using raw TCP socket programming. The system incorporates a simulation of the BB84 Quantum Key Distribution (QKD) protocol to derive AES-256 encryption keys for every message, and demonstrates real-time detection of Man-in-the-Middle, eavesdropping, and replay attacks across actual networked machines.

\section{Introduction}

Digital communication over untrusted networks remains one of the most important challenges in modern information security. Classical encryption algorithms such as AES and RSA are widely deployed, but they rely on computational assumptions that may eventually be broken by advances in quantum computing. Quantum Key Distribution (QKD), pioneered by Bennett and Brassard in 1984 through the BB84 protocol, offers a fundamentally different approach: it uses the laws of quantum mechanics to guarantee that any eavesdropping attempt disturbs the quantum channel and can be statistically detected.

This project bridges the theoretical domain of QKD with practical socket-level network programming. Instead of specialized quantum hardware, the system simulates the BB84 protocol in software, generating quantum bits and bases, performing basis sifting, measuring the error rate introduced by simulated interference, and deriving a shared AES key from the surviving sifted bits. This key is then used to encrypt the actual message payload before transmission over a raw TCP socket. The receiver independently reconstructs the error rate from the simulated quantum channel and blocks any message whose error rate exceeds the configured threshold.

The project is implemented as a two-tier system: a Python Flask backend that runs the BB84 simulation, AES-256-CBC encryption, nonce-based replay detection, and raw TCP socket server; and a React-based frontend dashboard that provides a real-time view of all cryptographic activity, peer discovery, inbox, and attack alerts.

\section{Problem Statement}

Classical network communication systems encrypt data using symmetric keys that are either pre-shared or exchanged via public-key protocols such as Diffie-Hellman or RSA. While these methods are computationally secure under current constraints, they offer no physical guarantee against interception. An attacker who silently records an encrypted session and later obtains computational power could decrypt it retroactively, an attack known as ``harvest now, decrypt later.''

Furthermore, conventional systems provide no inherent mechanism to detect whether a message was intercepted and re-forwarded, or whether a previously valid message is being replayed. Intrusion detection is typically handled at a higher layer through signatures, anomaly detection, or firewall rules rather than at the cryptographic key-exchange level.

The problem addressed by this project is the need for a practical, socket-level communication system that: (1) derives fresh encryption keys using a quantum-inspired protocol that mathematically detects eavesdropping, (2) operates over real LAN sockets without specialized quantum hardware, (3) detects and blocks MITM relay attacks by tracking packet routing paths, (4) prevents replay attacks using single-use cryptographic nonces, and (5) provides a live interactive dashboard showing all security events in real time.

\section{Motivation}

The motivation for this project comes from two converging trends. First, post-quantum cryptography and QKD are becoming increasingly relevant as quantum computers advance from theoretical curiosity to experimental reality. Students and practitioners in information security need hands-on exposure to these concepts. Second, raw socket programming is a fundamental skill in network security that is often skipped in favour of high-level abstractions.

By implementing BB84 simulation over real TCP sockets, this project provides a tangible, demonstration-ready platform that connects quantum cryptography theory to practical network programming. The interactive attack demonstrations --- where a user can switch between direct, eavesdrop, MITM, and replay modes and observe the effect on the receiver's inbox in real time --- make the system uniquely suited for educational purposes and project demonstrations.

\section{Objectives}

The main objectives of the QuantumHop project are as follows:

\begin{itemize}
    \item To implement the BB84 Quantum Key Distribution protocol in software, producing simulated Alice and Bob qubit streams, basis sifting, error rate calculation, and shared key derivation.
    \item To build a raw TCP socket server and client in Python that transmits and receives BB84-encrypted JSON envelopes between two physical laptops on a LAN.
    \item To implement AES-256-CBC encryption using the BB84-derived key, ensuring end-to-end confidentiality for all messages.
    \item To implement automatic peer discovery using UDP broadcast so that laptops on the same network detect each other without manual configuration.
    \item To demonstrate and detect three attack scenarios: eavesdropping (BB84 error rate spike), Man-in-the-Middle relay (unauthorized IP path), and replay attack (duplicate nonce detection).
    \item To build a React-based dashboard that provides real-time visibility into BB84 basis tables, error rates, AES key previews, network peers, inbox messages, and security alerts.
    \item To provide a single-command launcher script that automatically kills stale processes on required ports and starts all services cleanly.
\end{itemize}

\section{Scope and Relevance}

The scope of this project covers the complete implementation of a two-laptop P2P quantum-inspired secure messaging system. The system operates entirely on a standard LAN or mobile hotspot without any cloud infrastructure, specialized hardware, or third-party messaging service. All cryptographic operations, including BB84 simulation, AES encryption, nonce management, and attack detection, are performed locally by the Python backend.

The project is directly relevant to the fields of network security, cryptography, and quantum computing education. It demonstrates how quantum-inspired key exchange can be integrated into a conventional socket programming framework, providing a practical foundation for understanding how real QKD systems would differ (by using actual photon polarization) from classical key agreement protocols. The attack demonstration capability makes it uniquely suitable for live educational presentations in laboratory and conference settings.
